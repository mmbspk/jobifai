## Summary

Implements **issue #58** (PR1 of Epic #40): a foundation for versioned default resumes and cover letters, with content stored separately from rendered PDFs so artifacts can be recreated without LLM calls.

- **Schema (migration 033 + 034)**: `user_documents`, immutable `document_content_versions` (incl. `render_snapshot_json`), `document_original_files`, deduplicated `document_render_artifacts` + version refs, `user_document_defaults`.
- **Storage**: `BlobStore` with local adapter (`data/user_documents/`, override `JOBIFAI_DOCUMENTS_STORAGE`). Unique temp files + atomic publish; same-user SHA256 dedup for PDFs.
- **APIs** (JWT, owner-scoped): list documents; create/append resume & cover versions; AI improve/generate (metered); store originals; set defaults explicitly; download/preview PDF and originals; partial render success returns `201` + `render_status=failed` so clients can retry PDF without new AI.
- **Profile authority**: confirmed `resume_profile` unchanged by document flows; profile upload retains original bytes (does not auto-select defaults).
- **Outdated signals**: profile, default resume market, and document style drift vs last confirmed default set `document_defaults_meta` (no auto AI/billing).
- **Styles**: shipped styles live under `resume_markets/styles` (`documents.StylesDirRelative`); empty style uses market CSS, not the first stylesheet in the directory.
- **UI**: `/documents` — list, create, AI actions, edit→new version, preview/**Create PDF** for reconstructible versions without artifacts, set default (including uploaded originals as default resume).
- **Legacy**: `job_applications/` downloads unchanged; versions without snapshots are non-reconstructible (no silent live YAML label fallback).

**Out of scope (later issues)**: bot document-selection policy (#59), retention/cleanup (#60), exact LLM result caching, byte/queue caps.

## Migrations & configuration

- Goose: `033_user_documents.sql`, `034_document_render_snapshot.sql`.
- Optional env: `JOBIFAI_DOCUMENTS_STORAGE` (default `data/user_documents/`).
- Local disk storage is **transitional** — suitable for dev/single-node; does not address long-term disk growth (PR3 retention).
